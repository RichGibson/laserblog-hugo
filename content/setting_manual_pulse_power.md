When aligning the mirrors you want the power as low as you can while still seeing the laser marks on the tape. A pulse of 10 ms is more than enough to mark the tape for mirror alignment.

To set the output power use the control panel:

1. Menu
2. Function, then Enter
3. Laser Set, then Enter
4. Enter a number with the keypad
5. Use the arrows to move to Write

You can leave the control panel in that state, test the pulse power, and then change it again.

When I'm done aligning the mirrors I like to set the power to 'continuous' so that I can manually control the laser to do straight cuts to clean up the edge of material.
