# Laser Love and Beer

Source for https://laserloveandbeer.com/, a Hugo site about laser cutting, making things, and assorted other topics.

## Writing a post

1. Create a Markdown file in `content/`, for example `content/my_new_post.md`. The filename becomes the URL (`/my_new_post/`).
2. Start it with front matter like this:

   ```yaml
   ---
   title: My New Post
   date: 2026-11-08T18:45:00-08:00
   draft: false
   categories:
     - Laser
   tags:
     - laser
   ---
   ```

   - `date` must not be in the future, or Hugo will skip the post when it builds.
   - `draft: true` hides the post from the live site.
   - Categories in the top menu: Laser, ScaleIndependent, TIL, Maps, Family, Data, Misc. A post shows up under a menu item if it uses that category.
   - Optional cover image:

     ```yaml
     cover:
       image: /images/some_image.jpg
     ```

3. Put images in `static/images/` and link them as `/images/filename.jpg`.
4. Preview locally:

   ```
   hugo server
   ```

   Then open http://localhost:1313/. Add `-D` to include drafts.

## Making it go live

Commit and push to `main`:

```
git add content/my_new_post.md
git commit -m "Add post: my new post"
git push
```

The live site updated about a minute after a push on 2026-11-08, with no manual deploy step. That suggests Cloudflare is connected to the GitHub repo and runs `hugo` itself on each push. This is inferred from that one push, not checked in the Cloudflare dashboard.

If a push ever doesn't show up, build and deploy by hand:

```
hugo && npx wrangler deploy
```

## Architecture

- **Generator:** Hugo (extended). Built locally with v0.162.0.
- **Theme:** PaperMod, included as a git submodule in `themes/PaperMod`. After a fresh clone, run:

  ```
  git submodule update --init
  ```

- **Config:** `hugo.toml` holds the site title, base URL, theme settings, taxonomies (categories and tags), and the top menu. Raw HTML in Markdown is allowed (`unsafe = true`) because older posts brought over from WordPress contain inline HTML.
- **Content:** `content/` has most posts at the top level, plus subfolders `about/`, `family/`, and `data/`.
- **Static files:** `static/` is copied straight into the site. It holds images, PDFs (such as laser controller manuals), photo projects, and map tiles.
- **Theme overrides:**
  - `layouts/index.html`: custom home page
  - `layouts/_default/titlelist.html`: title-list layout
  - `layouts/partials/extend_footer.html`: footer additions
  - `assets/css/extended/blank.css`: custom CSS loaded by PaperMod: 960px main column, photo gallery grid, and home page thumbnails
- **Hosting:** Cloudflare. `wrangler.toml` tells Cloudflare to serve the `public/` directory as static assets.
- **Build output:** `public/` and `resources/` are generated by Hugo and are not in git (see `.gitignore`).
- **History:** The site was migrated from Pelican (`~/projects/laserblog`). Details are in `migration_report.txt`.
